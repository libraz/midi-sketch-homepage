# MIDI Sketch Homepage

Homepage for [MIDI Sketch](https://midisketch.libraz.net) - built with VitePress.

## Development

```bash
# Install dependencies
yarn install

# Start dev server
yarn dev

# Build for production
yarn build

# Preview production build
yarn preview

# Copy WASM from ../midi-sketch/dist
yarn copy:wasm
```
